# Security Policy

## Maintenance Status

This repository is officially in **Maintenance Mode**. As such, we are no longer providing active security updates, patches, or vulnerability monitoring.

## Reporting a Vulnerability

While the project is no longer actively maintained, if you discover a critical security vulnerability that could impact existing users who use this repo for reference, you are still welcome to report it. However, please be aware that a resolution or patch is not guaranteed.

## Recommendations

For any new production applications, we strongly recommend using actively maintained frameworks that provide regular security updates, such as:

- [NestJS](https://nestjs.com/)
- [Express](https://expressjs.com/) (with manual monitoring of dependencies)

It is the responsibility of the developer to ensure that any code adapted from this boilerplate is audited for security before use in a production environment.
